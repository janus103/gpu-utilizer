# ResNet50
- Pretrained: False (From Scratch)
- Optimizer: SGD
- Learning Rate (Base): 0.1 
- LR Scheduler: Cosine Decay 
- Epochs: 300
- Warmup Epochs: 5
- Loss: BCE Loss 
- Augmentation 
    -- Mixup: 0.1
    -- CutMix: 1.0
    -- Policy: RandAugmentation (rand-m7-mstd0.5-inc1)
- Weight Decay: (1 x 10e-4) ~ (2 x 20e-5)
- Label smoothing: 0.0
- EMA: True (0.9999)
- Drop Path : 0.05
- Gradient CLIP: None
- Timm Bash commands:  
CUDA_VISIBLE_DEVICES=0 python3 train.py --data-dir /home/oem/jin/datasets/imagenet --train-split train --val-split val \
      --model resnet50 --num-classes 1000 --input-size 3 224 224 \
      -b 256 -j 4 \
      --opt sgd --lr 0.1 --sched cosine --epochs 300 --warmup-epochs 5 \
      --bce-loss --mixup 0.1 --cutmix 1.0 --aa rand-m7-mstd0.5-inc1 \
      --weight-decay 20e-5 --smoothing 0.0 \
      --model-ema --model-ema-decay 0.9999 --drop-path 0.05 \
      --output ./output --experiment resnet50_scratch
